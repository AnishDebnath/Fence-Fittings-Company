# Fence Fittings Company

A modern, responsive landing page for **Fence Fittings Company**, a trusted Indian manufacturer and exporter of precision fence fittings and engineering components.

## 🚀 Key Features
- **Manufacturing Excellence**: ISO 9001:2015 certified with modern production facilities.
- **Global Reach**: Serving 4+ continents with millions of components exported.
- **Responsive Design**: Optimized for Desktop, Tablet, and Mobile.
- **Interactive UI**: Featuring smooth transitions, horizontal marquees, and dynamic grid layouts.

## 🛠️ Tech Stack
- **React 19**
- **TypeScript**
- **Vite** (Build Tool)
- **Tailwind CSS** (Styling)
- **Lucide React** (Icons)

## 📁 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation & Run
1. **Clone & Install**
   ```bash
   npm install
   ```
2. **Start Development**
   ```bash
   npm run dev
   ```
3. **Build for Production**
   ```bash
   npm run build
   ```
